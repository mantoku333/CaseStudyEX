# ストーリー本文の表示ルール

提供された「ストーリー仕様」に準拠。

| 表示 | 1行の最大文字数 | 1ページの最大行数 | 本文サイズ |
| --- | --- | --- | --- |
| 通常 | 30文字 | 2行 | 38 |
| 強調（`#size:1.5`） | 20文字 | 1行 | 57（通常の1.5倍） |
| 文字揺れ（`#shake`） | 20文字 | 1行 | 57（強調を併用） |

文字数によって本文を縮小しない。強調によって名前帯の大きさは変えない。
本文中の明示改行を尊重し、色などのリッチテキストタグは文字数に数えない。
上限を超える本文は表示ページを分け、文字を省略しない。

表示中のクリックで現在のページを全文表示し、次のクリックで次ページに進む。
最後のページを読み終えてから次の台詞に進む。ログには分割前の台詞を1件として記録する。

検証用プレビュー: Unity の `Tools > CaseStudy > Story > Verify and Export Event UI Previews`。
30/31/60/61文字と強調20/21文字、手動改行、リッチテキスト、ページ送りを検証する。


## ノクスの左右配置

- 通常は左。タナトスのセリフが出ると、その会話中は右へ移動する。
- 右側のノクスはイリスと別の Image で、イリスの背後に重ねて表示する。
- Yarn の行に `#nox:left` / `#nox:right` を付けると、会話途中でも配置を指定できる。
- 会話終了時に指定をリセットし、次の会話ではキャラクター設定の初期位置へ戻す。
- DialogueView の Nox Placement で左右それぞれの位置・サイズ・Z回転（Rotation）を調整できる。左配置は位置 (250, 250)、サイズ (418, 525)、Z回転20度。
- `Event99_ExpressionTest` 冒頭で左 → タナトス登場で右 → イリスとの重ね表示 → 左への復帰を確認できる。
- Unity メニュー `Tools/CaseStudy/Story/Verify and Export Event UI Previews` で配置・表示維持・アニメーション・リセットを検証し、`outputs/event-ui` に左右のプレビューを出力する。
- 現在の共有 Prefab にはタナトスの立ち絵登録がないため、タナトス本人の表示確認には素材登録が必要。

- 二人が右にいる配置：ノクス位置 (-113.4, 433.9)、サイズ (520, 650)、Z回転 -8.92度。イリス位置 (-180.5, 280)、サイズ (420, 560)、Y回転180度。`Nox Placement` の `Iris With Nox` 各項目で調整し、左配置へ戻る際と会話終了時にはイリスの元のTransformを復元する。
