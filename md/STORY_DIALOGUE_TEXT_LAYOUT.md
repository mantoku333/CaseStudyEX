# ストーリー本文の表示ルール

提供された「ストーリー仕様」に準拠。

| 表示 | 1行の最大文字数 | 1ページの最大行数 | 本文サイズ |
| --- | --- | --- | --- |
| 通常 | 30文字 | 2行 | 38 |
| 強調（`#size:1.5`） | 20文字 | 1行 | 57（通常の1.5倍） |
| 文字揺れ（`#shake`） | 20文字 | 1行 | 57（強調を併用） |

文字数によって本文を縮小しない。強調によって名前帯の大きさは変えない。
本文中の明示改行を尊重し、色などのリッチテキストタグは文字数に数えない。
上限を超える本文は表示ページを分け、文字を省略しない。

表示中のクリックで現在のページを全文表示し、次のクリックで次ページに進む。
最後のページを読み終えてから次の台詞に進む。ログには分割前の台詞を1件として記録する。

検証用プレビュー: Unity の `Tools > CaseStudy > Story > Verify and Export Event UI Previews`。
30/31/60/61文字と強調20/21文字、手動改行、リッチテキスト、ページ送りを検証する。
